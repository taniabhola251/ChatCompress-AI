# ChatCompress quick guide

## Start the app

Open PowerShell in the project folder and run:

```powershell
npm install
npm run dev
```

Open the address printed in PowerShell.

## Import a chat

1. Open the dashboard.
2. Paste chat text, or choose a `.txt` or `.zip` export.
3. Check the message count.
4. Select **Catch Me Up**.

A ZIP export must contain one `.txt` chat. Media files are ignored. ChatCompress reads it on your device.

## Explore the results

Use the menu to see the summary, priority inbox, tasks, deadlines, decisions, mentions, questions, and timeline. In the Priority Inbox, choose **High priority** to show high-priority messages. Newer dates appear first.

The demo uses made-up messages. Try it without importing a file.

## Important

ChatCompress uses simple rules, not an AI model. Its results may not always be correct. Check the original messages.

There is no WhatsApp account connection. The app does not upload your chats.
